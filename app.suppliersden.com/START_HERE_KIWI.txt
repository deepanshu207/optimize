KIWI BROWSER (ANDROID) — INSTALL THIS EXTENSION
================================================

THIS FOLDER is the extension. manifest.json is HERE (same folder as this file).

Before you zip, confirm you see:
  ✓ manifest.json
  ✓ content.js
  ✓ icons/
  ✓ Badge/
  ✓ js/

There must be NO file named _headers (Chrome/Kiwi block names starting with _).

--- ZIP ON COMPUTER ---

1. Zip THIS ENTIRE FOLDER (manifest.json at top level when unzipped).

2. Or run from repo root:
   bash scripts/build-extension-zip.sh

--- ON ANDROID (KIWI) ---

1. Remove the OLD extension first (Kiwi → Extensions → remove old Meesho Optimizer).
2. Copy the NEW zip to phone → unzip (must be v1.6.9+ with native category dropdown).
3. Kiwi → Extensions → Developer mode → Load unpacked
4. Select the folder with manifest.json
5. Open supplier.meesho.com → AI Optimizer button

You should see the same category search as browser web:
  - Text box: "Search by name or ID"
  - Dropdown results while typing
  - Press Enter or pick from list
  - Version badge like v1.7.0 in the yellow header

No license key needed — opens directly to Live / Test Lab.
